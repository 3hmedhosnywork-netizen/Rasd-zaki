# مرسال المواقع

تطبيق ويب تقدمي (PWA) لاستقبال روابط Google Maps من قائمة المشاركة في Android، وإسناد أكواد متسلسلة لها، وتجهيز إرسال الكود ثم الرابط كرسالتين منفصلتين عبر WhatsApp.

## النشر
ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم من Settings → Pages اختر Deploy from a branch، والفرع `main` والمجلد `/ (root)`. بعد النشر افتح رابط GitHub Pages في Chrome على Android ثم اختر تثبيت التطبيق.

## ملاحظات تشغيل مهمة
- البيانات تحفظ محلياً على نفس الجهاز والمتصفح.
- عند مشاركة رابط من Google Maps اختر «مرسال المواقع» من قائمة المشاركة.
- الإرسال إلى WhatsApp يحتاج اختيار المحادثة/المجموعة والتأكيد يدوياً؛ WhatsApp لا يسمح لموقع ويب بإرسال الرسائل إلى مجموعة بصمت أو اختيار مجموعة بعينها تلقائياً.
- بعد إرسال الكود، ارجع للتطبيق واضغط إرسال الرابط؛ وبعدها انتقل للموقع التالي.
