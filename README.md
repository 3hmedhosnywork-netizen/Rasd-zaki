# مرسال المواقع — نسخة التحديث

استبدل ملفات المستودع بهذه الملفات، ثم انتظر إعادة نشر GitHub Pages.

### تغييرات
- كروت مواقع أصغر.
- زر «مسح المكتمل» يحذف فقط العناصر المكتملة بعد تأكيد.
- استبدال أزرار تعديل/نسخ بـ «إعادة إرسال» مستقلة.
- إعادة إرسال موقع لا تغيّر حالة أو ترتيب الإرسال الجماعي.
- إرسال الكل يظل بالتتابع اليدوي: رابط + 5 أسطر فارغة + الكود، ثم الرجوع للتطبيق لإعداد الرسالة التالية.
- بيانات المواقع والترقيم محفوظة محليًا.
